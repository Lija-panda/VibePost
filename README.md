## 🌟 What is VibePost?

VibePost is a modern blog publishing platform that allows users to create, manage, and discover content through an elegant glassmorphic interface.

Built with Spring Boot's MVC architecture and powered by Spring Data JPA, VibePost delivers a seamless writing experience while maintaining clean backend architecture and scalable database management.

Whether you're documenting your journey, sharing technical knowledge, or building a content-driven application, VibePost provides the foundation to publish your ideas effortlessly.
